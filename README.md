# Advent of AI 2026

Puzzles by [TechWolf](https://techwolf.ai), at **[adventofai.techwolf.ai](https://adventofai.techwolf.ai)**.

A new puzzle opens every day in December. The puzzles are built to be solved by a human and a coding agent
together: fetching the data and running one algorithm is usually not enough. Some are easy, some are hard,
and since agents are not deterministic, you might get lucky.

This repository holds no puzzles or solutions. It is where you tell us when something is wrong.

## Reporting an issue

[Open an issue](../../issues/new) when:

- a puzzle page does not load, or a file or image will not download;
- an answer you are sure of is refused, or the answer box acts oddly;
- signing in, your profile, an API token or the leaderboard does not work;
- a puzzle text is unclear, or seems to contradict itself.

Please include:

- the day or name of the puzzle;
- what you did, what you expected, and what happened instead;
- the time it happened (with timezone), your browser, or your agent and how it calls the API.

**Never post an answer, a solution or a spoiler in an issue.** Issues are public, and other players read
them. If your report cannot be made without one, say so in the issue and we will find another way to talk.

Do not put API tokens, email addresses or other personal details in an issue either. If you posted a token
by mistake, replace it on your Profile page.

For prizes or jobs, use the contact boxes on your Profile page, not an issue.
